# Агент подбора квартиры

AI-агент на **Java 17 + Spring Boot 3 + Claude** (Claude API или Claude Code), который подбирает квартиру **для покупки или аренды** в любом районе по требованиям пользователя. Он проверяет каждое объявление и сообщает, что подходит, что нужно уточнить у продавца и почему остальные варианты отсеяны.

Все требования задаются в форме:

| Параметр | Варианты |
|---|---|
| Сделка | покупка или аренда |
| Районы / ЖК | любые, через запятую; пусто — все из базы |
| Бюджет | рубли или рубли в месяц |
| Спальни | студия, 1–4 или неважно; кухня-гостиная или отдельная кухня от заданной площади |
| Обязательно | балкон или лоджия, готовый ремонт, мебель, допустимы ли апартаменты |
| Желательно | выход на балкон из кухни, гардеробная / постирочная / кладовая |

Проект вырос из реальной задачи: найти квартиру с двумя спальнями, балконом и готовым ремонтом в ЗИЛАРТе или ЖК «Ривер Парк Коломенское». Эти требования стоят в форме по умолчанию как пример. В демо-базе 28 вымышленных объявлений в четырёх районах: ЗИЛАРТ, «Ривер Парк Коломенское», Хамовники и Митино.

## Как это работает

```
 источники объявлений          анализ и оценка                        Claude-агент
┌──────────────────┐     ┌────────────────────────────┐     ┌──────────────────────────────┐
│ DemoListingSource│──┐  │ ListingAnalyzer            │     │ AgentService: API или Code   │
│ (демо-база)      │  ├─▶│  текст → планировка,       │──┬─▶│  search_listings             │
│ ImportedListing- │  │  │  балкон, хранение, отделка │  │  │  get_listing_details         │
│ Source (свой     │──┘  │ MatchScorer                │  │  │  web_search (ЦИАН, Авито,    │
│ JSON-файл)       │     │  MATCH / CHECK / REJECT    │  │  │  Яндекс, ДомКлик)            │
└──────────────────┘     └────────────────────────────┘  │  └──────────────────────────────┘
                                                         └─▶ веб-интерфейс (Thymeleaf)
```

**1. Анализ по правилам** (`analysis`) работает без интернета и без ключей.

- Структурированным полям площадок доверять нельзя. Число балконов часто стоит «0» по умолчанию, а евротрёшку продавцы записывают и как «2-комн.», и как «3-комн.». Поэтому `ListingAnalyzer` разбирает **текст описания**, а поля использует только как подтверждение.
- Для каждого признака используется трёхзначная логика `YES / NO / UNKNOWN`. «Не указано» — это не «нет»: такая квартира не теряется, а попадает в группу «уточнить у продавца».
- **Число спален** определяется по тексту: «евро-3» — это две спальни и кухня-гостиная, «изолированная спальня и кухня-гостиная» — евродвушка, «две изолированные комнаты, отдельная кухня 12 м²» — две комнаты. Если из объявления не понять (например, «3-комн.» без описания), квартира попадает в «уточнить», а не отсеивается.
- Учтены тонкие случаи: французский балкон — это не балкон; кладовая для велосипедов на этаже — не место хранения в квартире; «два спальных места» — не две спальни; «с ремонтом, но без мебели» — отказ, если мебель обязательна.

**2. Claude-агент** (`agent`) подключается одним из двух способов. Оба реализуют интерфейс `AgentBackend`, а нужный выбирает `AgentService`.

| | `ClaudeApiAgent` — Claude API | `ClaudeCodeAgent` — Claude Code CLI |
|---|---|---|
| Оплата | по токенам, нужен ключ `ANTHROPIC_API_KEY` | входит в подписку Claude Pro/Max |
| Как работает | агентный цикл на Anthropic Java SDK (`claude-opus-5-5`): модель сама вызывает инструменты приложения `search_listings` и `get_listing_details` | приложение запускает `claude -p` и передаёт уже оценённые объявления через stdin; из журнала `stream-json` берёт ответ и считает вызовы инструментов. Личные скиллы, MCP-серверы и история пользователя отключены, чтобы ответ зависел только от запроса |
| Веб-поиск | серверный `web_search`, ограниченный сайтами недвижимости | встроенный `WebSearch` Claude Code |
| Для чего | сервер, развёртывание для других людей | личное использование на своём компьютере |

- В обоих режимах агент перепроверяет спорные объявления по полному тексту. Правила на регулярных выражениях могут ошибаться, а модель понимает формулировки вроде «спальня и кабинет — планировка свободная».
- Свежие объявления из интернета агент приводит со ссылками и честно помечает, что приложение их не проверяло.
- Ответ — рекомендация в Markdown: лучшие варианты, вопросы продавцу, итог.
- В режиме API включён серверный фолбэк на модель-замену при отказе. Для ошибок своя обработка: неверный ключ, лимиты, сбой сети, Claude Code не установлен или вход не выполнен.

## Запуск

Нужен JDK 17+. Maven ставить не обязательно — в проекте есть Maven Wrapper.

```bash
./mvnw spring-boot:run          # Windows: mvnw.cmd spring-boot:run
```

Откройте http://localhost:8080. Подбор по правилам работает сразу на демо-базе.

### AI-агент по подписке (без оплаты API)

1. Установите Claude Code — в PowerShell:
   ```powershell
   irm https://claude.ai/install.ps1 | iex
   ```
   На macOS и Linux: `curl -fsSL https://claude.ai/install.sh | bash`.
2. Один раз войдите: запустите в терминале `claude`, выполните `/login` и выберите вход через подписку Claude.
3. Запустите приложение. В режиме `app.agent.mode=auto` оно само найдёт Claude Code, и кнопка «Спросить AI-агента» станет активной.

Если `claude` установлен не в PATH, укажите путь явно: `--app.agent.claude-code-command=C:/путь/к/claude.exe`.

### AI-агент через Claude API

```bash
export ANTHROPIC_API_KEY=sk-ant-...      # Windows PowerShell: $env:ANTHROPIC_API_KEY="sk-ant-..."
./mvnw spring-boot:run
```

Если заданы и ключ, и Claude Code, в режиме `auto` используется API. Чтобы выбрать режим явно, задайте `app.agent.mode=api` или `app.agent.mode=claude-code`.

### Свои объявления

Свою подборку реальных объявлений можно положить в JSON-файл в формате [демо-базы](src/main/resources/data/demo-listings.json) и подключить так:

```bash
./mvnw spring-boot:run -Dspring-boot.run.arguments=--app.listings.import-file=/path/to/listings.json
```

Файлы `*.local.json` и папка `data/` исключены из git, поэтому личные данные в репозиторий не попадут.

> **Почему нет парсера ЦИАНа или Авито.** У площадок нет открытого API, а автоматический сбор данных в обход их защиты нарушает правила использования. Живые объявления агент ищет через веб-поиск Claude, а свою подборку можно загрузить файлом. Новую площадку с официальным API легко подключить: достаточно реализовать интерфейс `ListingSource`.

## Тесты

```bash
./mvnw test
```

- `ListingAnalyzerTest` — подсчёт спален, распознавание балконов, отделки и мебели на примерах реальных формулировок из объявлений.
- `ListingSearchServiceTest` — полный конвейер на демо-базе: вердикты и причины отказа для разных требований (однушка в Хамовниках, три спальни в Митино, «неважно»), фильтр по району, сортировка.
- `ClaudeCodeAgentTest` — разбор ответа Claude Code CLI, понятные ошибки, когда CLI не установлен или вход не выполнен.
- `WebLayerTest` — страницы отдаются, показывают подборку, снятый в форме флажок действительно отключает требование.
